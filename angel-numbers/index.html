How to read an angel number

Readers start with the digits. Each digit has a theme, from new beginnings (1) to completion (9). Repetition is read as emphasis, so 111 is 1's message turned up, and 1111 louder still. Then the digits are added and reduced to a root number for the overall theme.

It is folklore, not science: psychologists explain repeated sightings through the frequency illusion. Many people still find the pause useful. Read our full guide, angel numbers explained, or look up any number.
